四步驟流程 — 未取得使用者確認前不得跳級

本流程規範簡報產出。其他產出（單頁、報表、產品介面）不受四步約束，但品牌規範一律適用。

01
資訊密度與文本梳理 · 零程式碼

1a 先選資訊密度（精簡／標準／詳盡，附示意圖）。Claude Design 用對話表單，送出即確認；Claude Code 另發布示意頁，選完再出一題確認。
1b 照密度梳理大綱：讀取原始文本，主動梳理出資訊層級，拆解為適合 16:9 的頁數。輸出條列式的頁面內容——頁碼與主題、主副標題、內文重點或關鍵數據或階段流程。層級依文本屬性動態判斷（數據分析、流程步驟、論述對比各有不同結構），不套固定模板。
嚴禁向使用者暴露工程或設計模組名稱：Card、Grid、Flexbox、版型代號、component 名稱都不該出現在這一步的對話裡。
此階段不輸出任何程式碼。

需使用者確認後才進入 02
02
風格確認與 Design Token 映射

固定資產不隨風格改變：七色品牌色、Montserrat + Noto Sans TC、兩套 logo lockup、輔助色用量上限。任何參考來源都不能覆寫這些。字級表跟著版型走，各版型獨立。
詢問使用者選擇系統預設風格，或提供網站連結／圖片／風格關鍵字。
2a 先選簡報風格（附示意圖）：白底標準（預設）／墨底標準／六角幾何拼貼，每種是一套獨立版型。
2b 只問該版型的題目：白底、墨底問封面樣式、照片呈現（章節頁預設產出、卡片預設實心淺灰底、圓角固定標準）；六角幾何拼貼只問封面樣式。每題附示意圖與白話說明。Claude Design 表單送出即確認；Claude Code 選完再出一題確認。

邊角風格　固定標準圓角 16px，不隨參考來源改變。
圖片呈現　滿版、卡片內嵌、六角遮罩、留白分欄。漸層遮罩與雙色調不採用。
留白與密度　緊湊 Compact ↔ 大留白 Spacious。
容器與邊框　實心卡片、線框、無邊框純文字分欄、細陰影浮起。
03
生成與微調 · Delta Edit 鐵律
單一／區域變更
icon 大小、單頁內文、替換圖片 —— 只改動該頁或該區塊，不重新輸出全份簡報。
全域 token 變更
字級系統、標準色、底色 —— 為維持整份一致性，必須更新全份全域 token。

除使用者明確要求「重新生成全份簡報」，一律採最小範圍更新。
圖片一律使用可拖放的佔位框，並提醒使用者提供最終圖片。不得以動態關鍵字圖床填圖，不得生成圖像——來源優先 Magnific（已訂閱），其次 Unsplash、Pexels。

04
交付與字型安全檢查

依交付形式判斷：PDF、deck-panel 產出的 HTML 已嵌字型，不用提醒；.dc.html、PPTX、Keynote、Google 簡報要提醒使用者確認電腦已安裝標準字型，並附上載點：繁中 Noto Sans TC、歐文 Montserrat。
說明備援機制：未安裝時會降級為 PingFang TC／Microsoft JhengHei，斷行可能改變。
匯出 PPTX 前先確認字型就位——字型不同會改變斷行，是跑版最常見的原因。
