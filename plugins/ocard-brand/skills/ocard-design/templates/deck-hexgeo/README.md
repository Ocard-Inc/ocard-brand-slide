# deck-hexgeo：六角幾何拼貼

> 最後更新：2026-10-06（加上共用的存檔、編輯文字、下載；調整面板只在 Claude 裡出現）

Ocard 簡報的第二種整體風格。這個風格把參考版型裡的圓形、膠囊和色塊，都換成 Ocard logo mark 的六角形；顏色和字型照 Ocard 品牌規範。版面拆成一個個元件，依實際內容組合，不照抄參考版型。

成品是單一 HTML 檔，內建調整面板，Claude Code、Claude Design、直接發布成網頁連結都能用。

完整的配色對應、字級表、元件和示意頁，見 `../../guidelines/style-hexgeo.board.html`。這份風格板已和使用者逐項確認過。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `src.html` | 原始檔，裡面是 14 張示意頁。logo、mark、圖示用 `__LOGO_H__`、`__MARK__`、`__IC_*__` 這類代號佔位 |
| `build.py` | 組出成品 `ocard-deck-hexgeo.html`：嵌入 logo、六角 mark，並只取出用到的字嵌進檔案，斷網也能正確顯示 |
| `lucide_pick.py` | 把 Lucide 圖示名稱轉成可以直接貼進簡報的向量路徑（見「圖示」） |

流程：複製 `src.html` → 換成 Step 1 確認過的內容 → 保留需要的版型、刪掉用不到的頁面 → 執行 `python3 build.py` → 交付 `ocard-deck-hexgeo.html`（可以改檔名）。

## 固定規則（所有風格都一樣）

- **字型固定**：繁體中文用 Noto Sans TC，英文與數字用 Montserrat。不論哪種版型都不換字型。
- 版型裡**不放「/01」這種斜線編號**。
- 封底不放網址。

## 版面與顏色

- 頁面底色 `#FAFAFA`。
- 左側是 112px 寬的白色品牌側欄，右側圓角 40px、帶淡陰影。上方放 OFB logo mark，下方放直書的 `@ocard.for.business`。
  - 不要改回黃色側條：使用者看久覺得太刺眼。
- 內容從 left 176px 開始，頁碼離右邊 64px。
- 大色塊只用以下幾種顏色：
  - 淺灰 `#F2F2F2`／`#E8E8E8`。
  - 墨色 `#333333`：一頁最多一塊。
  - 品牌黃 `#FFEA00`：一頁最多一塊。同一組拼貼裡的黃色六角形算同一塊。
- 輔助色只用在小元素：分類點、重點長條、箭頭、小字。預設橘 `#FC6815`，面板可以改紫或青。黃色不能當輔助色。
- 圖示徽章只有兩種配色：墨底配黃色圖示，或淺灰底配墨色圖示。**不做黃色底的圖示徽章。**
- 長條圖不用黑色或黃色的長條。

## 六角形

- 一律是 logo mark 的形狀。圓角跟著尺寸等比例放大；拉長時只延長中間的平邊。由 `hexPath()` 產生，套用在每個有 `data-o` 的元素上。
- **方向**：

  | 元素 | 方向 |
  | --- | --- |
  | 照片遮罩、橫向膠囊、指標列色塊 | `data-o="h"`，平邊朝上下 |
  | 直向膠囊、直向長條 | `data-o="v"`，尖角朝上下 |
  | 圖示徽章、標題後的黃點、小標前的分類點、封面第二款左上的小六角、封底蜂巢 | **logo mark 原本的方向（`v`），不旋轉** |

- 封底蜂巢維持原本的排列（左黃、中淺灰與照片、右上墨），只把每顆轉成 logo mark 方向，所以縮小一些避免互疊。
- 六角形由程式畫出。頁面打開、尺寸改變、字型載入、切回分頁時都會重畫，避免載入時量不到尺寸而變成方塊。

## 版型（`src.html` 的 14 張示意頁）

| data-id | 版型 | 已確認的做法 |
| --- | --- | --- |
| `cover` | 封面 | 直向六角膠囊拼貼，墨、黃、灰三塊出血色塊 |
| `coverB` | 封面 · 第二款 | 墨色滿版底；左上六角拼貼；右上六角照片；大標題放右下。不放「PRESENTED BY」。兩款封面二選一，產出時只留一款 |
| `content` | 內文 · 雙欄 | 橫向六角膠囊照片，黃色標籤壓在照片角落 |
| `stats` | 數據 · 指標列 | 左邊是指標名稱和說明（三點緊密排列）；右邊色塊上方放數字。**同一組數字只出現一次** |
| `chart` | 數據 · 直向長條 | 高度照數值比例，一根用輔助色當重點。數值和期間放在長條頂端上方，**不加白底標籤** |
| `team` | 三欄 · 六角照片 | 六角照片加墨色徽章 |
| `summary` | 三行重點 | 短標與說明兩欄，細線分隔 |
| `pain` | 痛點列 | 墨色六角徽章後接橫向膠囊。膠囊左端接到徽章的頂端，不露白 |
| `market` | 市場層疊 | 三塊階梯式膠囊，數字直接寫在色塊上 |
| `flow` | 流程對照＋結論帶 | 三個正六角徽章用輔助色箭頭串成流程，不用長條膠囊表示步驟 |
| `table` | 墨色半版表格 | 右側墨色大色塊，表格從 left 820px 開始；左下是六角照片 |
| `cards` | 團隊照片卡 | 六角照片壓在橫向膠囊卡上；「我們的優勢」用黃色結論帶 |
| `budget` | 長條圖＋圖例 | 長條照比例，% 放在長條頂端上方；圖例的六角點是顏色對照，不開放換成圖示 |
| `closing` | 結尾聯絡 | 右側蜂巢，底部細線上放聯絡資訊，不放網址 |

**黃色結論帶**（關鍵效益、我們的優勢）：寬 820px、高 76px，**以上方內容的寬度置中**，不是以整頁置中；文字從帶子左端往內 60px 開始。

## 調整面板

操作方式和 `deck-panel` 一樣：
- 右上「調整」只顯示畫面中間那一頁的項目，捲動時自動換頁；不另放每頁的「調整這一頁」按鈕；「調整」按鈕和白底同樣式，與「編輯文字／存檔／下載」放在右上同一排（2026-10-06 起）。
- 正在調整的頁標「正在調整」，其他頁暫時變淡。
- 「恢復預設」只還原目前這一頁。
- 面板頁碼照投影片上印的頁碼。兩款封面都是 01。

| 項目 | 選項 | 範圍 |
| --- | --- | --- |
| 照片 | 每個照片位置：選擇／更換、－／＋、移除 | 只改這頁 |
| 輔助色 | 橘（預設）、紫、青 | 整份套用 |
| 編號（`summary`、`flow`） | 不加編號（預設）、六角編號、數字編號 | 只改這頁 |
| 左側六角（`pain`） | 圖示（預設）、編號：編號放進左側六角徽章 | 只改這頁 |
| 小標記號 | 六角點（預設）、圖示：每個小標各有 3 個依意思挑的圖示 | 只改這頁 |
| 徽章圖示 | 每個徽章 3 個依意思挑的圖示，第一個是預設 | 只改這頁 |

**存檔、編輯文字、下載**來自所有版型共用的 `../_shared/ocard-kit.js`（2026-10-06 起）：設定存在 `OcardKit.state.v`、照片存在 `OcardKit.state.photos`，按「存檔」才寫進檔案；在 Claude 以外打開是成品，沒有調整面板、照片鎖定。`python3 build.py 檔名.html --state 存檔來源` 把存檔內容寫進成品（同 deck-panel）。原本的 `KEY`、`IMGK` 瀏覽器存檔已移除。

### 換內容時要一起改的設定（都在面板 script 開頭）

| 設定 | 內容 |
| --- | --- |
| `NAME` | 每個 `data-id` 的頁名 |
| `HCH` | 小標文字對應的 3 個圖示 |
| `CHO` | 每頁徽章依序的 3 個圖示 |
| `LAB` | 徽章在面板上的名稱 |
| `SLOTNAME` | 照片位置在面板上的名稱 |
| `LUC` | 用到的 Lucide 路徑，由 `lucide_pick.py` 產生 |

## 圖示

- 來源只用 **Lucide**（`lucide-static` 0.544.0，ISC 授權，免標註），和其他 Ocard 模板相同，Claude Design 與 Claude Code 都一樣。24 格、2px 線、圓角端點、不填色。不可自己手繪，也不混用其他圖示庫。
- **每個小標、每個徽章都依它自己的意思挑 3 個**，第一個是預設。不可以給一整組共用清單，也不可以從固定的少數圖示裡挑「最接近的」。使用者明確要求過這一點。
  - 例：使命 → 旗幟、羅盤、火箭；回訪率提升 → 回訪、回店、定期；客服夥伴 → 客服、教育訓練、支援。
- **圖示是依當下文案挑的**：產出簡報時，依每個小標、徽章的意思各挑 3 個 Lucide 圖示（第一個是預設），面板上就是這 3 個選項。挑選時可以用 `python3 lucide_pick.py --search 關鍵字`（英文，比對圖示名稱與 Lucide 的標籤，例如 `--search loyalty`、`--search chart`）找候選。
- 挑好名稱後執行 `python3 lucide_pick.py 名稱1 名稱2 …`，把輸出貼進 `LUC`（key 是 `lu-名稱`），並在 `IN` 加上中文名稱。圖示會變成向量路徑嵌進簡報，打開簡報時不需要網路。
- 圖示庫放在 `../../assets/icons/lucide/`（`icons.json` 是全部 1,865 個圖示、`tags.json` 是搜尋用標籤），腳本先讀這裡，不需要網路；找不到這個資料夾時才從 npm registry 下載 `lucide-static` 0.544.0。
- 圖示顏色跟著輔助色（小標）或徽章配色。不使用 emoji。

## 照片

- 每個灰色六角形都能放照片：直接拖進去，或點一下選擇檔案；面板每頁也有「置入照片」。
- **Claude Design 裡只能拖放**：Design 的編輯環境點一下不會開啟選檔視窗，所以在 Design 裡不提供點選上傳和「選擇照片」按鈕，只能把照片拖進去。Claude Code、直接發布的網頁連結，拖放和點選都可以。
- 照片放進來時，預設是**剛好填滿框的最小尺寸**；「－」最小只能縮到這個大小。
- 拖曳時照片永遠填滿框、不露出底色：照片在哪個方向比框大，就只能往那個方向移動；要往另一個方向移，先按「＋」放大。
- 上傳時自動縮到 1600px 以內，存成 JPEG。
- 不使用動態關鍵字圖庫，也不生成圖像。照片來源照 `readme.md` 的選圖規則。
